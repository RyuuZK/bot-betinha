🤖 Betinha Bot
O Betinha Bot é o companheiro oficial para o seu servidor Discord! Um bot focado em diversão, sorteios aleatórios, interações entre membros e utilitários rápidos. Se você procura uma forma de agitar o chat, o Betinha é o cara (ou melhor, o bot).

🚀 Comandos Principais
Sorteios e Aleatórios
!quem: O bot sorteia alguém do servidor para ser o "culpado".

!traidor: Aponta um traidor entre os membros.

!viado: Sorteia um membro para o "prêmio" do dia.

!casal: Sorteia dois membros do servidor para formar um casal.

Jogos e Utilidades
!dado <lados>: Rola um dado com o número de lados que você quiser (ex: !dado 20).

!limpar <quantidade>: Limpa as mensagens do chat (apenas para moderadores).

Interação com GIFs
!beijo @membro: Envia um GIF carinhoso de beijo.

!tapa @membro: Envia um GIF de tapa para aquele amigo chato.

!sexo @membro: Envia um GIF de abraço romântico para o seu crush.

Oráculo
!qualquercoisa: Digite qualquer comando começando com ! que não exista, e o Betinha responderá com uma frase aleatória para decidir sua vida!
